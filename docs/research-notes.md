# PoisonGuard Research Notes

## 1. Adversarial Machine Learning

Adversarial Machine Learning studies attacks and mitigations
against machine learning systems.

## 2. Data Poisoning

Data poisoning is an attack in which an adversary manipulates
training data to influence the behavior of a trained model.

## 3. Backdoor Attack

A backdoor attack introduces a hidden pattern or trigger into
training data so that the model behaves maliciously when the
trigger is present.

## 4. Evasion Attack

An attacker modifies an input at inference time to cause
incorrect model behavior.

## 5. PoisonGuard Focus

Primary focus:

- Data poisoning
- Backdoor attacks
- Detection
- Mitigation
- Experiment tracking
